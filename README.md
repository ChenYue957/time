# ⏰ 时间看板 (Time Dashboard)

一个功能丰富的网页时间看板，集实时校时、考试倒计时、世界时钟、农历显示于一体。

🔗 在线演示：[time.chenyue.fun](https://time.chenyue.fun)

---

## ✨ 功能特性

### 🕐 时间面板

- **高精度实时时钟**：显示时/分/秒/毫秒，50ms 刷新
- **日期与农历**：公历日期 + 干支纪年 + 农历月日
- **时区与星期**：自动检测当前时区
- **世界时钟**：8 个常用城市时区，点击可锁定/切换主时钟时区
- **全屏模式**：点击时钟进入沉浸式全屏显示

### 🎯 校时面板

- **网络校时**：通过 timeapi.io / 阿里云 mtop 获取服务器时间
- **偏移计算**：显示设备时间与标准时间的毫秒级偏差
- **状态指示**：绿色（<100ms）、橙色（<1s）、红色（>1s）三级提示
- **自动同步**：每分钟自动重新校准

### 📋 考试看板

- **考试管理**：添加、编辑、删除考试安排
- **预设科目**：语/数/英/物/化/生/政/史/地 9 科快捷选择，支持自定义
- **智能时长**：按科目自动匹配默认时长，支持自定义分钟数
- **倒计时**：实时显示剩余/距开考时间
- **全屏投影**：考试进行中或即将开始时可全屏展示，含左侧考试列表
- **数据持久化**：考试数据存储在 localStorage，刷新不丢失

### 👤 作者面板

- 作者信息与主页链接

## 🚀 部署方式

### 本地预览

```bash
# 使用 Python
python3 -m http.server 8080

# 或使用 Node.js
npx serve .
```

然后访问 `http://localhost:8080`

### 静态托管

直接将项目文件部署到任意静态托管服务：

- **GitHub Pages**
- **Cloudflare Pages**
- **Vercel / Netlify**
- **阿里云 OSS + CDN**
